# SnapStudio

A photography studio booking and client-gallery platform.

## Version 1 scope
- Public studio website and photography packages
- Session booking request flow
- Client gallery experience with favourites and download affordances
- Photographer workspace preview
- Booking calendar and payment workflow foundations

## Stack
- Next.js App Router
- React + TypeScript
- Custom responsive CSS

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current implementation status
This first milestone establishes the responsive website and interactive front-end experience. Booking submission, authentication, private storage, payment processing, and email delivery require backend services and environment credentials before they can be treated as live production features.

## Planned integrations
- Supabase Auth, Postgres and Storage
- Paystack test-mode deposits
- Resend booking and gallery-ready emails
