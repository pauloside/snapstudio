# SnapStudio — Style Guide

## Brand direction
Editorial, warm, calm and photography-led. The interface should feel considered and premium without making the booking process difficult.

## Visual system
- **Display type:** Playfair Display for large editorial headings.
- **Interface/body type:** DM Sans for navigation, forms, labels and body copy.
- **Palette:** warm off-white and cream surfaces, charcoal text, muted olive/sage accents, restrained warm neutrals.
- **Photography:** large, natural-looking images with consistent cropping and generous whitespace. Use studio-owned images before real public launch. Clearly identify any temporary illustrative imagery.
- **Shape:** simple rectangular cards with restrained borders; avoid excessive shadows and decorative effects.
- **Motion:** subtle transitions only; respect reduced-motion preferences.

## Components
- Primary button: dark charcoal background, light text, clear hover/focus states.
- Secondary action: text link or quiet outline.
- Package card: package name, short description, Naira price, inclusions and booking action.
- Form field: visible label, helpful hint, clear validation message.
- Status label: plain language such as Requested, Awaiting deposit, Confirmed, Completed or Gallery ready.
- Gallery photo: image preview, accessible favourite control and selection state.

## Content rules
- Use Nigerian Naira (₦) for displayed prices.
- Use real studio contact/location details only after the owner confirms them.
- Current package prices are starter assumptions for the preview, not approved commercial rates.
- Do not invent customer testimonials, ratings or studio credentials.
- Avoid lorem ipsum and generic placeholder copy in the final submission.

## Accessibility
- Maintain readable text contrast.
- Every form field has a programmatic label.
- Buttons and icon-only actions have accessible names.
- All interactions are keyboard accessible and show visible focus.
- Provide useful alternative text for meaningful photographs.
- Do not communicate booking/payment status by colour alone.

## Responsive breakpoints
Use the existing responsive CSS approach and test narrow mobile, tablet and desktop widths. Keep the booking form and gallery controls usable on mobile.
